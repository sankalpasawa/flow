Phase 3 — Product Brief

8 P0 Features to Test the Bet

  • Infinite humor feed — text jokes + image memes, endless scroll
  • Category sections — dad jokes, dark humor, memes, one-liners, Indian
  • WhatsApp share + OG preview — the viral loop
  • Like / Dislike — simple personalization
  • AI joke generation — type topic, get jokes
  • Content pipeline — 3 APIs + AI + dedup
  • Optional auth — save prefs across devices
  • Mobile-optimized web — opens from WhatsApp

PR/FAQ Positioning

FOR Priya, a busy doctor who wants a quick laugh,
MAZE IS a never-ending humor feed
THAT delivers curated + AI jokes, shareable to WhatsApp.
UNLIKE 9GAG (toxic) or Instagram (algorithm noise),
MAZE is humor-only, clean, and every shared link pulls people back.

Top Risks

  • AI jokes aren't funny enough — mitigate: AI supplements, not primary
  • No retention — mitigate: personalization + fresh content daily
  • WhatsApp loop fails — mitigate: preview must show the joke itself

Phase 5 — Architecture

Tech Stack

LayerChoice
FrameworkNext.js 16 (App Router)
StylingTailwind CSS v4 + shadcn/ui
BackendSupabase (Postgres + Auth)
AIVercel AI SDK v6 + Claude
ContentJokeAPI + DadJoke + HumorAPI
DeployVercel (CDN + Cron + Edge)
AnalyticsPostHog (before 100 users)
OG Imagesnext/og (ImageResponse)

Why This Stack

  • SSR mandatory — WhatsApp crawler doesn't execute JS. OG tags must be server-rendered.
  • Founder knows it — Same stack as DayFlow + PPR. Zero learning curve.
  • Vercel AI Gateway — Swap models without code changes. Observability built in.
  • $0/month at launch — All services on free tier. Scale when needed.

The Operating System

11 Active Functions

Every department defined — scoped to Stage 1 (pre-launch, 0 users).

  • Product — Decide what to build. Say no to everything else.
  • Design — Design-in-code. Tailwind + shadcn. Visual QA after each feature.
  • Engineering — Build feed, pipeline, sharing flow, AI generation.
  • Content — Seed 500+ jokes. Set up cron ingestion. AI generation.
  • Security — Don't expose API keys. Supabase RLS. Privacy policy.
  • Quality — Test on mobile. Test WhatsApp sharing. Check OG previews.
  • Growth — WhatsApp viral loop IS the growth strategy.
  • Data — Track D1, share rate, session duration, scroll depth.
  • Ops — Git push. Vercel auto-deploys. That's it.
  • Finance — Don't run out of API credits. Track costs.
